# Awesome Starlight [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of awesome things related to Astro Starlight

[Starlight](https://starlight.astro.build/) is a full-featured documentation theme built on top of the Astro framework. It's designed to help you build beautiful, high-performance, and accessible documentation sites.
